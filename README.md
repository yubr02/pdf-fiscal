🚀 Sobre o Projeto

O PDF Fiscal Generator é um sistema desenvolvido para simular a geração de documentos fiscais em PDF, representando uma funcionalidade essencial em sistemas comerciais e ERPs.

O projeto foi criado com foco em resolver um problema real:
👉 gerar documentos fiscais organizados, padronizados e prontos para uso.

🎯 Objetivo

Demonstrar na prática:

Geração de PDFs com dados estruturados
Simulação de documentos fiscais reais
Aplicação de lógica de negócio
Estrutura de projeto voltada para sistemas empresariais

🚀 Como Executar
# Clone o repositório
git clone https://github.com/yubr02/pdf-fiscal

# Acesse a pasta
cd pdf-fiscal

# Instale as dependências
pip install -r requirements.txt

# Execute o projeto
python main.py

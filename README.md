# SmartPOS PDV

Sistema de Ponto de Venda desktop para mercado/mercearia com:

- Back-end Java Spring Boot
- Front-end desktop Electron
- Banco MySQL

O projeto foi organizado em monorepo:

- `backend`: API REST, regras de negócio e integração com MySQL
- `frontend`: aplicação desktop Electron
- `database`: scripts SQL de criação e carga inicial
- `docs`: documentação complementar

Consulte o guia de execução em `docs/como-rodar.md`.
